# Amefdam's Site

Personal website, portfolio and development lab built as part of my **DAM (Multiplatform Application Development)** studies and independent learning.

🌐 **Live website:** [amefdam.42web.io](https://amefdam.42web.io/)

## About the Project

A personal space to document my learning process, showcase projects, collect technical knowledge and experiment with different technologies.

Think of it as a mad scientist's laboratory: a place for experiments, achievements, mistakes, functional hacks and occasional spectacular failures. The goal is not to present everything as a finished product, but to learn by building, document the process and turn ideas into practical projects.

## Planned Sections

- **About Me:** A short introduction and the purpose of this website.
- **Projects:** Personal and academic projects, including their descriptions, technologies and source code.
- **Knowledge Base:** Technical notes, explanations and learning resources.
- **Lab:** Experiments, prototypes, small applications and other side projects.
- **Links:** Relevant profiles, repositories and external resources.

The website is under active development. Sections and features will be added progressively as the project evolves.

## Technologies

Currently used:

- HTML5
- Git and GitHub
- GitHub Actions for automated deployment
- InfinityFree for web hosting

Additional technologies, such as CSS, JavaScript, PHP and MySQL, may be incorporated as the project develops.

## Development and Deployment

The source code is maintained in this repository. Changes pushed to the `main` branch trigger an automated deployment to InfinityFree using GitHub Actions and FTP.

The general workflow is:

1. Modify the source files locally.
2. Commit the changes with Git.
3. Push the changes to GitHub.
4. GitHub Actions deploys the updated files to the web server.
